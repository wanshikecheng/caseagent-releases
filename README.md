# 万事柯成 · 病历书写助手（安装包发布）

本仓库用于发布「万事柯成病历书写助手」Android 安装包（APK），供用户下载与版本归档。

## 下载方式

1. **官网（推荐，速度快）**：https://wanshikecheng.xin
2. **本仓库 Release（备用/归档）**：见右侧 [Releases](../../releases) 页面，选择最新版本下载对应 APK
3. **应用内更新**：已安装用户打开 App 会收到更新提示

## 版本说明

每个 Release 包含：
- APK 安装包
- 文件 SHA256 校验值（用于验证下载完整性）

## 安装说明

1. 下载 APK 到手机
2. 点击安装（如提示"禁止安装"，请在系统设置中允许来自该来源的安装）
3. 打开 App，按引导填写自己的 AI 模型服务配置（BYOK）

## 软件简介

面向临床医生的病历书写辅助工具：本地语音识别、智能文书生成、门诊接诊记录、医学知识库、文书一键传输。
数据本地优先存储，语音识别在设备端完成，不上传音频。

> 本软件为文书书写辅助工具，生成内容需由执业医师审核后使用。
