## 软件简介

面向临床医生的病历书写辅助工具，主要功能：

- **智能文书生成**：对话式描述病情，按规范结构生成入院记录、首次病程记录、查房记录、出院记录等文书草稿
- **本地语音识别**：内置中文语音识别引擎与医学词库，按住说话即可转写，全程在设备本地完成（不上传音频）
- **门诊接诊助手**：口述问诊内容自动整理为主诉、现病史、体格检查、辅助检查等客观记录栏（不生成诊断与用药建议）
- **医学知识库**：本地存储与检索，作为文书书写参考
- **文书一键传输**：通过外接无线输入设备将文书直接发送至电脑
- **隐私保护**：数据本地优先；发送前可自动擦除姓名、身份证号、手机号等标识信息
